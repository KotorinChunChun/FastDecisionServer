# fds自動起動設定（2026-10-07）

ユーザーの依頼により、Windowsサインイン時の自動起動を現在のユーザーのRunキーに登録した。autostart.ps1で登録・解除・確認を再現できる。非表示のpwshから既存fds.ps1を呼び出し、デバイスはautoとする。起動済みの場合は既存サーバーを維持する。

検証: PowerShell構文検査成功、登録のEnabled=Trueを確認、同じ起動スクリプトの実行成功、healthの応答を確認した。実際のPC再起動・再サインインによる検証は未実施。推論処理とモデルには変更を加えていない。
