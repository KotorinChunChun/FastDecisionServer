# 開発資料

FDSの要求・判断・開発経緯・検証記録の目録です。現行の利用方法とAPI契約は[README](../README.md)・[利用ガイド](../docs/USER_GUIDE.md)・[API仕様](../docs/API.md)・[開発者ガイド](../docs/DEVELOPERS_GUIDE.md)、資料の配置規則は[AGENTS.md](../AGENTS.md)を参照してください。

## 現行版と記録の読み方

2026-10-07時点でソースの版は **v0.3.0** です。Cloudflare Clefの接続実装・模擬検証と実接続の未確認範囲は[v0.3.0実装記録](history/v0.3.0/v0.3.0-imp.md)にあります。常駐上限6組・自動解放禁止への変更と当時の実機確認は[v0.2.2実装記録](history/v0.2.2/v0.2.2-imp.md)にあります。実行中の版・デバイス・常駐状態はhealthで確認し、履歴のPIDや測定値を現在の状態と扱わないでください。

historyとtestingは、それぞれの日時・版・条件で得た記録です。後続の検証は古い結果を書き換えず、別の証跡として参照します。初版時点の未測定事項を、後続確認なしに現在の未実装や再試験要求へ読み替えません。

## 作業・配布

- [配布規則](RELEASE_RULE.md)：検証、除外対象、ライセンス、公開と正常終了の制約。
- 構築・運用・測定スクリプトは `dev/scripts/`。実行方法は[開発者ガイド](../docs/DEVELOPERS_GUIDE.md)と各測定記録を参照。
- 作業中の版別資料はdev直下、完了した一式はhistoryへ移す。正式な履歴はGitで追跡し、測定の生出力は `dev/testing/output/` としてGitから除外する。
