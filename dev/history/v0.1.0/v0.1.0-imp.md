## 2. 要件別の方式

- 共用サーバー: FastAPI/uvicorn、ループバック、CLI `fds`。OpenAPI は `/openapi.json`、対話仕様は `/docs`。
- モデル交換: `config.json` のモデルID→固定revision/checkpoint/backend/画像能力。未登録IDは拒否する。
- 画像: PNG/JPEG/WebP の data URL を枚数・バイト・画素数で制限し、1024px以内へ正規化する。
- CPU/GPU: `auto/cpu/cuda` を各要求に保持し、単一ワーカー内でロードから全質問実行まで完了させる。
- 待ち列: 有限優先待ち列、満杯は429。期限/切断後は結果を破棄し、実推論終了まで次の推論を開始しない。
- 管理: 起動時の準備はワーカーより先に順序保証、停止開始後は新規要求を拒否、現在の計算が終わって終了。
- 検証: 模擬backendで契約と競合を検証。実機は同じAPIから短文と合成画像を測定し、平均・中央値・p95の標本数を明記する。

## 3. 影響範囲

## 4. 追加対応
